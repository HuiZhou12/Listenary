# 更新日志

从 **3.0.0** 起。每个版本默认折叠，点版本号展开。最新：**3.2.0**。

完整发布页：[GitHub](https://github.com/HuiZhou12/Listenary/releases)

<details>
<summary><strong>3.2.0</strong></summary>

**新增**

**主页**

- **全新聚合主页**：从上到下依次为你呈现「再听一遍」「好久没听」「猜你喜欢」「关注的艺人」「推荐歌单」和「你的回顾」。
- **更聪明的老歌推荐**：「再听一遍」和「好久没听」会根据你的听歌习惯智能推荐，并自动打散同一歌手或专辑的歌，避免刷屏。
- **多平台独立加载**：「猜你喜欢」「推荐歌单」「关注的艺人」按平台独立加载，某个平台加载失败不会拖累其他平台；无内容的模块会自动隐藏。
- **本地听歌回顾**：「你的回顾」会根据本机记录，为你统计近 30 天常听曲目、历史总播放次数以及最喜爱的歌手。
- **清晰的报错提示**：模块加载失败时不再直接消失，而是提示具体原因并提供重试按钮；如果是账号登录过期或未配置，也会明确提醒。

**探索页**

- **全新探索页**：汇集排行榜、新碟、新歌、分类歌单与平台精选，所有内容均标明来源平台。
- **歌单分类墙**：提供四行可横向滑动的分类标签墙，点击即可进入对应分类歌单。
- **更顺畅的浏览**：歌单列表滑到底部自动加载更多；「新专辑」与「新歌」拥有各自独立的详情列表页。

**在线艺人页与专辑页**

- **在线艺人主页**：包含歌手名片、热门歌曲（默认展示 5 首，可展开查看全部）、专辑、单曲与 EP。若原平台无相关数据则自动隐藏对应模块。
- **在线专辑主页**：展示高清封面、发行年份与完整曲目列表，点击歌手名或专辑名可直接跳转。

**搜索**

- **搜索框二合一**：本地与在线搜索合并到同一个弹窗，顶部可一键切换「本地」或「在线」结果。
- **分类秒切**：在线搜索结果支持按「全部」「单曲」「专辑」「艺人」筛选，切换分类无需重新加载。
- **直达详情页**：搜索结果可直接点开专辑或艺人主页；若当前未配置任何可用音源，「在线」选项会置灰并引导你前往设置。

**在线播放**

- **指哪播哪**：支持拖动进度条或直接点击某行歌词跳转播放，修复了跳转时进度条“先回弹再前进”的怪异现象。
- **操作更顺手**：如果音频暂时无法跳转，会提示原因并回到当前播放位置；播放页新增「更多」菜单，方便快速查看歌手、专辑、收藏或加入歌单。

**多平台支持**

- **来源一目了然**：收藏夹、订阅、歌单及播放历史全面加上平台角标，跨平台听歌不再分不清来源。

**设置**

- **卡片式音源管理**：在线音源设置改为“一平台一卡片”，顶部自带总开关，展开后可精细配置各项功能接口。
- **支持自定义音源**：新增「添加提供商」，支持手动添加自定义音源平台（同名平台会自动加上简短标识以示区分）。
- **接口测试工具**：支持表单与代码两种配置视图。配置后可对单项功能进行可用性测试，测试报告会明确指出“可用”、“未确认”或“失败”，并帮你定位具体是配置、网络还是数据解析出了问题。

**启动**

- **全新启动画面**：冷启动时加入品牌标识淡入动画，后台同步完成初始化，好看且不拖慢启动速度。
- **统一默认首页**：无论首次安装还是日常打开，启动后统一默认进入「主页」。

**修复**

**在线播放**

- 修复了非网易云音源在音质自动降级时没有提示的问题。
- 区分了「歌曲本身无歌词」和「平台不支持歌词」的提示文案，不再笼统显示为“暂无歌词”。
- 修复了自定义音源平台的歌词全部显示为“暂无歌词”的 Bug。

**艺人与专辑**

- 修复了合唱或多艺人歌曲点击「查看艺人」时，总是只能跳到第一位歌手的问题，现在每位歌手都能单独点开了。
- 修复了软件重启后，「继续听」和「我的收藏」里的歌手、专辑点不开的问题。

**列表与页面**

- 修复了窗口较窄时，页面标题被裁切、操作按钮被挤变形的问题。
- 修复了收藏列表加载失败时，被误提示为“没有收藏”的问题（现在会正常报错并提供重试）。
- 移除了普通歌单里每首歌前面的数字序号，版面更清爽（仅排行榜保留名次序号）。
- 修复了已置灰（不可播）的歌曲依然会被塞进「播放全部」队列的问题。
- 修复了在搜索弹窗里点开专辑或歌手页后，新页面被搜索框挡住无法操作的问题。
- 修复了窗口高度较矮时，设置页里的部分平台配置项点不到的问题。

**歌单**

- 修复了点击排行榜封面会“自动订阅并跳转”的问题，现在点击封面仅打开预览，需手动点击才会订阅。
- 修复了刷新订阅歌单后，歌单内所有歌曲的「添加时间」都被重置为当前时间的问题。

**多平台**

- 修复了单个平台搜索报错会导致其他正常平台的结果也无法显示的问题，以及主页推荐模块偶发一直加载失败的问题。
- 修复了自定义音源平台开关失灵、且被系统误识别为网易云音乐的问题。

**优化**

**性能**

- 大幅优化了歌词发光特效与逐字缩放的性能开销，动画更省资源，歌词滚动不再抖动。

**界面与主题**

- 统一了全软件的提示气泡、文字链接与列表悬停的配色，现在它们会自然跟随当前主题色，不再出现突兀的纯黑或纯白。
- 统一了各页面的加载中、空内容与报错状态的视觉风格。
- 主页底部的平台说明与设置页的音源卡片默认收起，界面首屏更干净。
- 精简了侧边栏，移除「在线音乐」独立入口（相关内容现已全面融入「探索页」与「搜索」）。

**无障碍**

- 为各级标题补充了语义层级，方便读屏软件按结构跳转；完善了在线歌曲列表的读屏标签，不可播放的歌曲不再误播报“播放”按钮。

**设置与凭据**

- **音质设置解耦**：全局设置改为设定“偏好音质级别”（并展示各平台对应档位）；在播放页临时切换音质，不再强行改动全局默认设置。
- **防误触保护**：使用“一键兼容填充”配置时，改为合并现有设置并弹窗确认，避免不小心清空原有配置。
